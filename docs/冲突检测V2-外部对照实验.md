# 外部对照与规则合取消融

把「实验报告」补成同一任务上的对照：LLM judge（工业默认）+ 规则合取消融。不是官方 NLI 服务，也不是和 VitaminC 原论文数字横比。

## 0. LLM 环境

OpenAI 兼容接口：

```bash
export WEKNORA_JUDGE_BASE_URL='https://api.openai.com/v1'   # 或你们实际网关
export WEKNORA_JUDGE_API_KEY='...'
export WEKNORA_JUDGE_MODEL='gpt-4o-mini'                     # 换成现用模型名
```

不要把 key 写进 Git 或贴进聊天。

## 计分口径

- Winner：正例必须选对文档；负例任何 winner 算 unsafe。
- Pair：与 cascade 同一 `expected_conflict`，报 P/R/A。
- 不得与官方 VitaminC train/dev/test 或合成 1.000 池化。
