# 外部对照与规则合取消融

把「实验报告」补成同一任务上的对照：LLM judge（工业默认）+ 规则合取消融。不是官方 NLI 服务，也不是和 VitaminC 原论文数字横比。

## 0. LLM 环境

OpenAI 兼容接口：

```bash
export WEKNORA_JUDGE_BASE_URL='https://api.openai.com/v1'   # 或你们实际网关
export WEKNORA_JUDGE_API_KEY='...'
export WEKNORA_JUDGE_MODEL='gpt-4o-mini'                     # 换成现用模型名
```

不要把 key 写进 Git 或贴进聊天。

## A2 规则合取消融（离线，先跑）

不调模型。对冻结 synthetic holdout 重打分：

```bash
cd ~/weknora
git pull --ff-only origin arena/01a01e71-weknora

make experiment-c410-fact-eval \
  MATRIX_RUN="$HOME/weknora-private-corpus/synthetic-policy-v1/runs/holdout-r3-retry1" \
  SPLIT=holdout \
  OUTPUT="$HOME/weknora-private-corpus/synthetic-policy-v1/fact-eval-ablation" \
  OVERWRITE=1
```

看 `report.md` 里 Issuer only / Issuer + date / Date + version 相对 All-source proposal 的 precision / unsafe。

路径若不同，改成你机器上已冻结的 holdout matrix 目录（需含 `matrix_manifest.json` 与各 detector 产物）。

  PUBLIC_MANIFEST="$HOME/weknora-public-data/vitaminc-real-v1-retry3/pair_eval_manifest.json" \

manifest 路径按你机器上已冻结 plan 调整。不要把 pair 正文贴进聊天；把输出 JSON 的 `metrics` 对象贴回来即可。

## 计分口径

- Winner：正例必须选对文档；负例任何 winner 算 unsafe。
- Pair：与 cascade 同一 `expected_conflict`，报 P/R/A。
- 不得与官方 VitaminC train/dev/test 或合成 1.000 池化。
