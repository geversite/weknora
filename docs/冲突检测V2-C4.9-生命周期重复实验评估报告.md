## 1. 目标与实验边界

C4.9 验证 C4.6 global winner proposal、C4.7 explicit adoption 与 C4.8 durable reopen 是否能在真实服务链路中完成多次独立执行，并在不安全 metadata 条件下 fail closed。

它通过：

```text
真实 HTTP API
真实 Asynq
真实 PostgreSQL
配置的模型
临时实验 KB
```

运行，不依赖 UI，也不直接写入 PostgreSQL。

本报告仅支持：

```text
在明确构造的 controlled policy scenarios 中，winner proposal/adopt/reopen 与 no-proposal guards
可以完成重复的 integration/safety 验证。
```

本报告不支持：

```text
真实业务文档泛化
人工审阅准确率
真实用户工时节省
provider RNG seed-controlled 因果结论
```

## 2. Matrix 设计

正式 matrix：

```text
run: 20260903T022509Z-c49_winner_lifecycle_matrix-b3c65b81
replicates: 3 independent executions
case definitions: 5
case executions: 15
seed control: none; independent replicates only
```

| Case | 预期 policy | 生命周期 coverage |
|---|---|---|
| `ordered_triplet_two_cycles` | 同 issuer V3 为唯一 winner | 2 轮 adopt → reopen |
| `out_of_order_triplet` | 乱序摄取仍由 metadata 选 V3 | 1 轮 adopt → reopen |
| `cross_issuer_no_proposal` | issuer 不同，abstain | adoption/reopen 均 HTTP 409 / no mutation |
| `date_version_disagreement_no_proposal` | date/version 方向不一致，abstain | 两个 no-action guard |
| `date_version_tie_no_proposal` | date/version tie，abstain | 两个 no-action guard |

raw conflict 是 chunk-pair 粒度；事实级断言以 DisputedFact 为主，不把 raw row 波动当作独立 gold 样本。

## 4. Dead-letter 后验核验

正式 C4.9 matrix 运行于自动 dead-letter 聚合 gate 加入之前，故需要对保存的 15 个 detector artifacts 进行只读后验核验。

执行命令：

```bash
find "experiments/comparisons/20260903T022509Z-c49_winner_lifecycle_matrix-b3c65b81/replicates" \
  -type f \
  -path '*/detector/metrics.json' \
  -exec jq -r '.dead_letter_count // -1' {} + \
  | sort \
  | uniq -c
```

用户实际输出：

```text
     15 0
```

因此：

```text
detector artifacts found: 15
dead_letter_count = 0: 15
dead_letter_count unknown/nonzero: 0
```

这补齐了 formal C4.9 matrix 的 dead-letter 完整性记录。后续 runner 已在 `a3921a3` 中进一步强化：任何 unevaluable detector execution 都不能被空 winner list 错计为 no-proposal TN，headline P/R 会标为 incomplete/null。

## 5. 结论

C4.9 可冻结为：

```text
controlled C4.6/C4.7/C4.8 lifecycle integration and safety replicate matrix
```

它证明了：

```text
- global proposal 不依赖 raw A/B 或摄取顺序；
- explicit adoption 的 stale / no-proposal guard 能 fail closed；
- durable reopen 可精确恢复 adoption 记录的 targets；
- issuer mismatch、metadata direction disagreement、tie 均不会强行选 winner；
- 15 个完整 detector artifacts 无 dead letters。
```

它仍不能替代：

```text
- C4.10 扩展 synthetic holdout 的 baseline 证据；
- 真实语料与双审阅；
- 现实 authority hierarchy / 复杂版本语义；
- 真实业务泛化结论。
```
