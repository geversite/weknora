## 1. 结论

C2-Lite 已在真实服务、真实异步队列、真实模型和真实 PostgreSQL 环境中完成：

```text
C2-A：保守确定性 claim 规则
C2-B：batch LLM 裁决、closed-world prompt、正例原文 grounding
C2-C：conflict_detection_runs 持久化成本指标
C2-D：V1 / C1 / C2-Rules / C2-Batch 脚本化消融与离线比较器
```

最终 C2-B4 全文档运行通过了本阶段的 detector integrity 条件：

```text
P1 / P2 / P3_P4_P5：全部命中
12 个 forbidden document pairs：均未出现
dead_letter_count：0
batch → single fallback：0
```

此前 P3 的 isolated fallback 场景已验证：0 个 exact claim candidate、2 个 semantic
fallback candidate 在 1 次 batch LLM 调用中检出冲突，且没有单对 fallback。B4 后的
P3 回归由运行者确认通过。

与当前 C1 单对 LLM baseline 相比，最终 C2-B4 的 conflict-detection 阶段观测为：

```text
实际 provider calls：48 → 9     （-81.25%，5.33× fewer）
LLM total tokens：48,762 → 28,528（-41.50%）
检测 task duration：145.154s → 75.789s（-47.79%）
```

这是 **冲突检测 LLM 阶段**成本，而非整个摄取 pipeline 的成本：不含 claim extraction、
embedding、解析和数据库查询。

## 3. C2-B 迭代的实验结论

### 3.1 初始 batch 的负面结果

早期 `rules_batch` 实验虽命中预期对，却产生了 7 条额外 raw conflict，涉及：

```text
doc1 ↔ doc2
doc1 ↔ doc3
doc2 ↔ doc3
doc3 ↔ doc5
```

模型理由显示典型开放世界错误：把“未提及”理解为否定、补充不存在的组织伦理前提、
把风险与材料属性或防护措施理解为互斥。该结果没有被当作成功结论，而是成为 B2 的
closed-world / proof-carrying 修正输入。

### 3.2 Closed-world + evidence guard

B2 要求每个 batch positive 带 A/B 连续原文证据，后端逐侧校验引文。全量 `c1_full`
新增 forbidden document-pair 断言，使“预期正例命中但额外误报”不再被标记为完整通过。

该修正消除了上述 closed-world 误报，并保留 P3 isolated fallback 的 batch 召回。

### 3.3 选择性 fallback

一次完整 batch 曾因 `pair-004` 的 `evidence_a` 无法在源文本定位而退回 C1。旧实现会
让整个 8-pair batch 退回，形成：

```text
10 batch + 8 single = 18 provider calls
```

B3 将结构错误与单条无证据 positive 分开：前者仍整批 fallback，后者重试后只 fallback
该单条。实测降为：

```text
10 batch + 1 single
```

这证明 failure isolation 不削弱 grounding guard。

### 3.4 Fallback schema drift

B3 的强 precision-first fallback prompt 曾漏 P1。其原因不是模型未抽取事实，而是：

```text
幽能引擎原型机 @ 测试时间
幽能引擎原型机测试 @ 计划开始时间
```

两个 extractor schema 产生不同 claim_key，P1 必然由 semantic fallback 裁决。B4 为
fallback pair 注入至多两组字符 bigram slot-similarity ≥0.35 的 prompt-only claim hints，
并要求仍以 A/B 原文引用确认。最终 B4 恢复 P1，且没有重新引入 forbidden 对误报。

## 4. 自动抽取 P/R 与 C2 的关系

本矩阵中 legacy `evaluate.py` 的 claim extraction 结果为：

| Variant | 自动 P | 自动 R | evaluator gate |
|---|---:|---:|---|
| C1 | 0.585 | 0.603 | fail(exit=1) |
| C2-Rules | 0.535 | 0.603 | fail(exit=1) |
| C2-B4 | 0.543 | 0.603 | fail(exit=1) |

这不是 C2 裁决层的 P/R，原因是：

1. C2 不修改 claim extractor；每次 run 的 production-model extraction 有波动；
2. `evaluate.py` 是开发/校准语料的 strict+relaxed claim matching，不是 conflict verdict
   precision/recall；
3. C1 已有独立人工审计口径：broad-maintenance human-adjusted P/R 为
   `0.867647 / 0.842857`，narrow conflict-critical recall 为 `1.0 (15/15)`；
4. 这些人工指标也不是新的 C2-B4 holdout 指标，不能被移植为 C2 的正式 paper score。

因此本报告保留自动 P/R 和 exit code，但只用 detector integrity、P3 isolation 和 cascade
metrics 判断 C2-Lite 的本阶段行为。

## 5. C2-Lite 冻结范围

**关闭条件：通过（研究原型，不是论文最终结果）。**

- [x] C1 legacy / C2 rules / C2 batch 的 KB 级可重复切换；
- [x] C2-A 的同值、数值异值、scope 不相交、gray-area 保守规则；
- [x] C2-B 的完整 batch JSON、bounded retry、结构性 fallback；
- [x] closed-world prompt、positive source-grounding、选择性无证据 fallback；
- [x] fallback schema drift 提示，不升级为不安全的 fuzzy direct rule；
- [x] `conflict_detection_runs` 的候选、规则、调用、token、延迟 durable metrics；
- [x] c1_full 正/负文档对断言、P3 isolated fallback、离线 V1/C1/C2 comparison；
- [x] 最终 C2-B4 scenario-level integrity pass，且实际 LLM 调用相对 C1 降低超过 5×；
- [ ] 多 seed / 多模型重复、真实 holdout、第二审阅者（论文实验前置）；
- [ ] conflict type 的严格 `version_update` 语义与文档元数据校验（C3）；
- [ ] raw chunk-pair conflict 聚类为事实级对象（C4）。

当前 `doc5 ↔ doc2` 在最终 B4 运行中标为 `version_update`，但该 P2 语义更接近
`fact_contradiction`。文档对检出不受影响；类型精度不在 C2-Lite 关闭门槛内，应在 C3
利用明确版本/日期/权威元数据后再评估。

## 6. 研究有效性与下一步

1. 所有 `claims_eval` 文档和 prompt 已参与迭代，属于 development/calibration corpus；
2. 单次完整 matrix 不能替代跨 seed 置信区间；
3. batch source grounding 能约束正例引用，但不能代替人类对复杂事实关系的审阅；
4. 现有 `knowledge_conflicts` 是 chunk-pair 行，`4` 或 `5` 条 raw rows 不是 `4` 或 `5`
   个独立争议事实；
5. C2 的 provider metrics 不含 claim extraction，任何报告都不得称“整个摄取成本下降
   41.5%”。

下一里程碑为 **C4-Lite：DisputedFact 聚类**。最小研究实现应先完成：

```text
raw knowledge_conflicts
→ 按稳定 claim/fallback 事实锚点聚类
→ 一组来源/候选值对应一个 DisputedFact
→ 以 cluster 级脚本/API 导出评估人工裁决次数
```

wiki dispute block 写回、前端重构和 agent 叙事合并均不应阻塞第一版 C4-Lite 聚类实验。
